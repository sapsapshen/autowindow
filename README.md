# ☁️ AutoWindow AI

> 浏览任何网页，按下快捷键，AI 已读完整篇内容在等你。

---

## 它能做什么

每打开一个网页，AutoWindow AI 就自动把页面内容读完。想了解这篇文章的核心观点？想翻译某段外文？想让 AI 帮你总结、改写、对比——直接问就行。

不需要复制粘贴，不需要切换窗口。**AI 就在页面底部。**

## 三步开始

**1. 安装插件**

Chrome 地址栏输入 `chrome://extensions/` → 开启「开发者模式」→ 加载已解压的扩展程序 → 选择本项目文件夹。

**2. 填入 Key**

点击浏览器工具栏的 AutoWindow 图标 → 完整设置 → 填入 DeepSeek API Key → 保存。

**3. 开始对话**

打开任意网页，`Ctrl + Shift + K` 呼出对话框，或者页面底部的浮动按钮一键展开。

## 用起来是什么感觉

- 📖 打开一篇英文论文，输入「用中文总结核心结论」——几秒出结果
- 🌐 浏览技术文档，问「这段代码有什么问题」——AI 已通读上下文
- 📰 看新闻时问「对立观点是什么」——它帮你梳理
- ✍️ 写邮件时让 AI 润色措辞——选中文字直接对话

**你只管提问，它已经看过这页了。**

## 内置模型

默认搭载 DeepSeek V4 系列，Pro 版擅长深度推理，Flash 版响应更快。在对话框左下角一键切换，也可以在设置页添加更多兼容模型。

## 界面

苹果风格磨砂玻璃面板，半透明浮在页面底部。不遮挡核心内容，不用时折叠为一个小圆点。
